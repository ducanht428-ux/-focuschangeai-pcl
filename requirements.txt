# Python 3.10+ recommended (matches MediaPipe Tasks and Ultralytics support).

# --- Vision: detection + tracking (Layer 1) ---
ultralytics>=8.2.0          # YOLO11 + built-in ByteTrack/BoT-SORT trackers
opencv-python>=4.9.0        # frame IO, ROI cropping, drawing

# --- Identity: face recognition + roster matching (Layer 2) --- OPTIONAL, NOT installed by this file
# Left out on purpose, for two reasons measured on an i5-5200U class laptop: onnxruntime-gpu has no CUDA
# to bind to, and insightface needs a compiler, so a plain "pip install -r requirements.txt" died on
# exactly these two lines and everyone blamed their own machine instead of this file.
# Nothing else breaks without them: identity.py imports insightface lazily and the run prints
# "identity off (ModuleNotFoundError: No module named 'insightface') - every track stays a guest".
# What that costs, said plainly: a guest-only run still writes class_live, but NO sessions/bands/presence
# document, because those three are keyed per bound student. To get identity back on a machine that can
# build it, run these two by hand:
#     pip install onnxruntime
#     pip install insightface
# (onnxruntime-gpu only on a real CUDA box.)
# insightface>=0.7.3
# onnxruntime-gpu>=1.17.0

# --- Detailed face/eye measurement (Layer 4) ---
# Same face_landmarker.task asset the Android app ships, so blendshapes line up 1:1.
mediapipe>=0.10.14

# --- On-screen text ---
# main.py draws the HUD and the plate text with PIL, lazily inside the draw helpers: a machine
# without Pillow opens the window and then fails the first time it paints a line, which is worse
# than failing at install. opencv's own putText cannot do the Vietnamese diacritics.
Pillow>=10.0.0

# --- Configuration (and Layer 5's data file) ---
# PyYAML reads config.yaml. Layer 5 itself needs no package at all: it is sqlite3, which ships with
# Python. firebase-admin used to be listed here and is gone - nothing in edge-server talks to a
# cloud service any more, so a machine with no internet stores exactly what it measures.
PyYAML>=6.0
